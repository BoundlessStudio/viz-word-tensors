# viz-word-tensors
Word Explorer to view word tensors nearest neighbors

Open the [live Word Explorer](https://vectors.rgbknights.com/) to see how sentence context changes a word’s neighbors in MiniLM.

## Run locally

From the repository root, run:

```sh
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000/). The first visit downloads MiniLM into your browser.
