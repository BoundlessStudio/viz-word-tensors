Field notes.

How MiniLM measures a word in context and how to read the map.

One word, several neighborhoods

A concert can bring a stage, an audience and an encore to mind. In “the two agencies acted in concert,” the same spelling describes cooperation. “Concert pitch” points to a tuning standard. And in a music prompt, a live concert might evoke distant applause, an open microphone or the reverb of a hall.

These are different relationships. Some are meanings of the word, some are things that occur nearby, and some are qualities you might ask a music model to produce. Explore individual sentences to see which distinctions a particular representation picks up.

What MiniLM measures

On first use your browser downloads the runtime, MiniLM’s matching WordPiece tokenizer and about 23 MB of model weights. MiniLM reads your sentence on your device. The explorer takes the final-layer vector for the focus word, averaging its pieces when the word spans several tokens.

The nearest-neighbor list ranks a finite set of reference words, each measured in isolation. Featured words such as “concert” have curated reference panels. Other words can be explored against a general panel. MiniLM was trained for sentence embeddings, so its token-level rankings can be surprising.

Words, tokens and context

A tokenizer can split a word into several pieces. The fingerprint panel shows the pieces MiniLM used. If the same word occurs twice, the explorer inspects the first occurrence.

MiniLM can use words on either side of the target. A causal GPT-style model can use only the prefix through that token when computing its state. To test the effect of a later clue in such a model, inspect a later token or put the clue before the focus word.

Every point here comes from MiniLM. For a music prompt, the map shows how MiniLM represents its language. GPT, Claude and Suno each have their own internal representations.

Reading the geometry

The map fits principal component axes to a set of reference vectors. Changing the sentence keeps the reference frame fixed for that focus word. A two- or three-dimensional view loses information, so a point that appears close on screen can rank lower in the full space.

Cosine similarity measures the angle between vectors. A value of 1 means the directions align, 0 means perpendicular and −1 means opposite. Scores express directional alignment. The legend colors identify editorial word groups.

The fingerprint shows the vector components in their original order. The final similarity readout compares the contextual vector with the same word in isolation. Choose Compare contexts to see a diamond for each example usage in that same projection. The comparison table measures similarity both to the isolated word and to the sentence currently selected.
